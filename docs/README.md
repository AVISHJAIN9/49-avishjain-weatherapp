## How to Run & Deploy the Documentation Site

### Running Locally
```bash
# Install dependencies (VitePress, Mermaid)
npm install

# Start local documentation server with Hot Module Reloading
npm run docs:dev

# The documentation server will launch at: http://localhost:5173
```

### Production Build & Preview
```bash
# Build static HTML/CSS production bundle to docs/.vitepress/dist
npm run docs:build

# Preview the production build locally
npm run docs:preview
```

### Deploying Online
- **Vercel / Netlify:**
  - Build Command: `npm run docs:build`
  - Output Directory: `docs/.vitepress/dist`
- **GitHub Pages:**
  - Configured via GitHub Actions workflow deploying the `docs/.vitepress/dist` artifact on pushes to `main`.
