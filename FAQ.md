# Frequently Asked Questions: Glassmorphic Weather Dashboard

### 1. What is Glassmorphic Weather Dashboard?
Glassmorphic atmospheric weather dashboard with dynamic forecast visuals and geolocation search.

### 2. What technology stack does it use?
Built with HTML5, Glassmorphism CSS, Vanilla JavaScript, Weather API.

### 3. Where is this project deployed?
Hosted live at: https://avishjain9.github.io/49-avishjain-weatherapp/

### 4. How can I run it locally?
Follow the installation and setup guide provided in [docs/SETUP.md](docs/SETUP.md) or the repository `README.md`.
