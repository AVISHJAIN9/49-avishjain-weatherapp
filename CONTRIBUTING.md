# Contributing to Glassmorphic Weather Dashboard

Thank you for your interest in contributing to **Glassmorphic Weather Dashboard**!

## Code of Conduct
This project follows the [Contributor Covenant 2.1](CODE_OF_CONDUCT.md).

## Development Workflow
1. Fork the repo and create your branch: `git checkout -b feature/your-feature-name`.
2. Commit with clean semantic messages (`feat:`, `fix:`, `docs:`, `perf:`).
3. Submit a Pull Request describing your additions.
